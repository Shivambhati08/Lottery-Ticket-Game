# Lottery Ticket

A fun and interactive Lottery Ticket application built with React. The application generates random lottery numbers and checks whether the generated ticket is a winning ticket based on a predefined winning condition.

## Features

- Generate random lottery tickets
- Display ticket numbers dynamically
- Check winning conditions automatically
- Interactive and responsive UI
- Built using React functional components
- State management with React Hooks

## Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
